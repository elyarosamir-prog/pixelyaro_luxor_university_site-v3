# موقع بيكسليارو — عرض جامعة الأقصر

موقع ثابت (Static Site) بديل عن ملف الـ PowerPoint، بنفس المحتوى بالظبط، بحجم أصغر بكتير (حوالي 13 ميجا بدل 500 ميجا).

## المحتوى
- `index.html` — الصفحة الرئيسية (كل المحتوى)
- `assets/css/style.css` — التنسيق
- `assets/js/main.js` — التفاعلات (سكرول، الجاليري، اللايت بوكس)
- `assets/img/` — كل الصور (مضغوطة WebP)
- `assets/video/` — الفيديوهات الثلاثة
- `assets/brand/` — شعار بيكسليارو

## أهم قرارين اتخدوا أثناء البناء
1. **الأخطاء الإملائية** اتصلحت في النصوص بس (مثلاً "مرغوع" → "مرفوع"، "ميديا هب" → "ميديا هاب" بشكل موحّد). المعنى والمحتوى الأصلي متغيرش.
2. **مكان الـ QR كود** في سلايد "بيكسليارو" وسلايد "لوج أوف" اتحول لزرار (CTA Button) بدل الصورة، والرابط اتقرا مباشرة من كود الـ QR اللي إنت عملته بنفسك:
   - زرار بيكسليارو → `https://q.me-qr.com/o3ot3mbj`
   - زرار Log Off → `https://q.me-qr.com/vtb550f4`

## النشر على GitHub + Vercel

### الخطوة 1: ارفع المشروع على GitHub
```bash
cd اسم-المجلد
git init
git add .
git commit -m "بيكسليارو - عرض جامعة الأقصر"
git branch -M main
git remote add origin https://github.com/USERNAME/REPO_NAME.git
git push -u origin main
```
(غيّر `USERNAME/REPO_NAME` باسمك واسم الـ repo اللي هتعمله على GitHub)

### الخطوة 2: اربطه بـ Vercel
1. ادخل [vercel.com](https://vercel.com) وسجل دخول بحساب GitHub.
2. دوس **Add New → Project**.
3. اختار الـ repo اللي رفعته.
4. **Framework Preset:** اختار **Other** (الموقع HTML عادي، مش محتاج build).
5. سيب باقي الإعدادات زي ما هي ودوس **Deploy**.
6. بعد دقيقة هتاخد لينك جاهز (`your-project.vercel.app`) تقدر تبعته للدكاترة.

كل مرة تعمل تعديل وتعمل `git push`، فيرسيل هيحدّث الموقع تلقائيًا.

## ملاحظة عن الفيديوهات
الفيديوهات التلاتة متضمنة جوه المشروع (`assets/video/`) وبتشتغل مباشرة جوه الصفحة (`<video controls>`) — مفيش لينكات خارجية مطلوبة.
